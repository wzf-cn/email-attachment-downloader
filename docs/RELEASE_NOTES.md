# 邮件接收管理 1.4.3

Windows x64 桌面版，无需安装 Python 或 .NET 运行时。

## 下载
- 推荐安装版：MailIntake-Setup-1.4.3.exe，支持安装、更新和卸载。
- 便携版：MailIntake-win-x64.zip，完整解压后运行 MailIntake.exe。
- 校验文件：SHA256SUMS.txt。

## 功能
多邮箱接入，按关键词归档正文及附件；每条规则独立设置下载目录和检查频率。支持姓名/学号校验、规则模板、大小限制、自动回复、异常停收和管理员重置。

提供中英文界面、常用邮箱默认参数、启动检查更新和自建意见反馈。界面使用新的信封图标；微信、支付宝和 PayPal 自愿赞助入口已接入。

## 上手与更新
请先阅读仓库 README 的五步上手。安装新版时会询问退出旧软件，配置和下载记录保留。便携版按 Update.cmd 说明更新。

26 项业务测试和隔离界面检查通过；尚未完成真实邮箱收发验收。发布包未做数字签名，Windows 可能提示安全提醒。QQ 云附件仅记录链接；Outlook OAuth 登录暂未提供。
