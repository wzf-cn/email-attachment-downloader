# Windows 安装包

使用 NSIS 3.12，当前用户安装，无需管理员权限。程序默认放置于 `%LOCALAPPDATA%\Programs\MailIntake`；应用数据仍在 `%LOCALAPPDATA%\MailIntake`，下载目录仍由每组规则指定。

支持中文安装向导、选择程序目录、开始菜单启动与卸载快捷方式、Windows 已安装应用卸载入口、覆盖升级。安装版请使用新版安装包升级，保持卸载清单与程序一致。

安装和卸载开始替换文件前，检查应用互斥锁。正在运行时询问是否退出，选择是则发出已有的安全退出事件，等待最多 60 秒。拒绝、旧版无事件接口或超时均中止操作；静默运行遇到已启动应用会中止，不自动关闭。持有互斥锁直到安装/卸载进程结束，防止替换过程中重新启动软件。

卸载只删除构建时生成的程序文件清单与快捷方式，不递归删除程序目录，不删除配置、数据库或用户下载内容。仅在启动项指向本安装目录时删除该启动项。

验证命令：先运行 `scripts/build-installer.ps1 -TestPackage`，再运行 `scripts/test-installer.ps1`。测试使用独立的安装标识、注册表项及临时数据目录，覆盖安装、已安装程序启动、升级数据保留、静默更新拒绝运行中应用、卸载清单与数据保留。测试产物留在临时目录，方便复核。交互式确认弹窗尚未进行鼠标操作自动化测试；安全退出事件在桌面版前次验证中已通过。

安装包尚未进行代码签名。
