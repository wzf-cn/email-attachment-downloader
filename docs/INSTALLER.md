# Windows 安装包

1.0.11：安装前逐一检查现有程序文件是否可写；文件仍被占用时先等待，再提供重试或取消，不进入文件替换阶段。检查以 OPEN_EXISTING 打开文件，不截断、不写入。增加安装实例锁，避免多个新版安装程序同时运行。安装回归测试包括独占 Accessibility.dll 时拒绝静默升级、释放后升级成功。

使用 NSIS 3.12，当前用户安装，无需管理员权限。程序默认放置于 `%LOCALAPPDATA%\Programs\MailIntake`；应用数据仍在 `%LOCALAPPDATA%\MailIntake`，下载目录仍由每组规则指定。

支持中文安装向导、选择程序目录、开始菜单启动与卸载快捷方式、Windows 已安装应用卸载入口、覆盖升级。安装版请使用新版安装包升级，保持卸载清单与程序一致。

安装和卸载开始替换文件前，检查应用互斥锁。正在运行时询问是否退出，选择是则发出已有的安全退出事件，等待最多 60 秒。拒绝、旧版无事件接口或超时均中止操作；静默运行遇到已启动应用会中止，不自动关闭。持有互斥锁直到安装/卸载进程结束，防止替换过程中重新启动软件。

卸载只删除构建时生成的程序文件清单与快捷方式，不递归删除程序目录，不删除配置、数据库或用户下载内容。仅在启动项指向本安装目录时删除该启动项。

验证命令：先运行 `scripts/build-installer.ps1 -TestPackage`，再运行 `scripts/test-installer.ps1`。测试使用独立的安装标识、注册表项及临时数据目录，覆盖安装、已安装程序启动、升级数据保留、静默更新拒绝运行中应用、卸载清单与数据保留。测试产物留在临时目录，方便复核。交互式确认弹窗尚未进行鼠标操作自动化测试；安全退出事件在桌面版前次验证中已通过。

安装包尚未进行代码签名。

## 软件更新检查
运行设置提供“启动时检查软件更新”（默认开启）和“检查软件更新”。两个公开仓库同时查询，只接受形如 v1.3.3 或 1.3.3 的正式版本；取较新版本，不把预发布版、草稿或普通源码提交作为更新。每次启动检查一次，每个请求最多等待 12 秒，不读取或上传邮箱配置、邮件或附件。启动检查失败时保持安静，手动检查会提示网络状态。

发现新版本后，经用户选择打开对应官方发布页，用户下载安装包并启动安装。安装器询问退出旧程序并保留本机数据。便携版用户下载 ZIP 后按原有 Update.cmd 流程更新。本版不在后台下载或执行安装文件。

维护者需要在 GitHub / Gitee 的 Releases 中创建正式版本并上传对应安装包、便携包和 SHA256SUMS.txt；仅提交源码或创建标签不会形成可用发布。建议两个平台使用相同标签和完全相同的安装文件。公开发布前确认版本、附件和校验值一致。

接口参考：https://docs.github.com/en/rest/releases/releases#get-the-latest-release ；https://gitee.com/api/v5/swagger 。本次开发实测两个 latest 接口均返回 404，目前未检测到可用正式发布。
